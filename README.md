Deterministic forecaster for each GTA VI (PS5) trophy's Exophase earn rate in week one: a saturating log-time trend fit on the last 24 hours of reads combined with an earners-over-players-tracked count model, with an honest logit spread that widens with the horizon and with unseen-refresh risk.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
